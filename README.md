# Клиент-серверное приложение BMI + PostgreSQL

## Описание

Консольный клиент на Python, работающий с базой данных PostgreSQL.
Позволяет рассчитывать индекс массы тела, сохранять историю и удалять записи.

## Требования

- Python 3.10+
- PostgreSQL 15+
- psycopg2-binary

## Запуск

1. Создайте БД и таблицу (см. методические указания).
2. Укажите параметры подключения в bmi_client.py.
3. python bmi_client.py
